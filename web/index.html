Escribe lo que necesitas en lenguaje natural. Atajos: barra para buscar, j y k para moverse, Enter para abrir y Escape para cerrar.

Skillscope descubre por su cuenta las skills, plugins, marketplaces y servidores MCP para Claude Code publicados en GitHub, explica qué hace cada uno, cuándo usarlo, cómo instalarlo y qué riesgos tiene. El índice se reconstruye cada ~30 minutos y el puntaje es público y auditable.

Las recomendaciones son siempre repositorios de GitHub; las redes sociales solo aportan la señal de cuánto se habla de cada uno. Un análisis automático no reemplaza tu revisión: lee el código antes de instalar.
